# Heglau — Erde. Hände. Eigenes Ding.

[Die Website besuchen](https://glaubi.net/heglau2/)

Ein neuer Blick auf einen kleinen Ort in Mittelfranken. Dieses unabhängige Dorfporträt erzählt von zwei Betrieben, die Heglau ihren eigenen Charakter geben: der Töpferstube Tanja Keim und dem Familienbetrieb Merkendorfer Kraut.

Originalfotos bringen die Keramik, den Krautanbau und den Hofladen ganz nah. Große Typografie, helle Flächen, dunkle Geschichten und ein leuchtendes Grün geben dem Ort eine neue Bühne. Beim Scrollen wechseln die Perspektiven; auf dem Handy steht jedes Foto direkt bei seiner Geschichte. Eine Bildergalerie zeigt die Details, und am Ende stehen die Informationen für einen Besuch.

Die Website lädt Bilder und Schriftarten lokal. Sie verwendet keine Cookies, kein Tracking und keine eingebetteten Drittanbieter. Die Inhalte bleiben auch ohne Animation und JavaScript lesbar.

Fotos und Informationen stammen von der [Töpferstube Tanja Keim](https://toepferstube-tanjakeim.de/) und [Merkendorfer Kraut](https://merkendorfer-kraut.de/). Bildrechte verbleiben bei den jeweiligen Rechteinhabern. Das Porträt ist keine offizielle Website der Betriebe oder der Stadt Merkendorf.
