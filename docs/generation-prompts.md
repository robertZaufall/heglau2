# Media direction

No image or video generation was used for this redesign. All seven photographs are originals from the user-supplied businesses. See [content-sources.md](content-sources.md) and [photo-sources.json](photo-sources.json).

The older version's generation prompts and site files are preserved locally in `output/redesign-backup/`; inherited media is archived in `output/legacy-media/`. Neither directory is published.

The revised [illustrated-scroll-site skill](../skills/illustrated-scroll-site/SKILL.md) separates original photography from optional generated illustration and video. Its photographic direction is an editorial composition built from real source material, not a prompt for synthesizing lookalike products or places.
